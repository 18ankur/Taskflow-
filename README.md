

# TaskFlow

### Get things done. Without the clutter.

TaskFlow is a simple task-management product concept designed for people who
want to organize their daily work, stay focused, and track progress without
unnecessary complexity.

## Live Demo

[View TaskFlow Live](https://18ankur.github.io/taskflow/)

## Features

- Simple task management
- Interactive task completion
- Automatic progress tracking
- Responsive design
- Mobile-friendly at 390px
- Desktop-friendly at 1440px
- Clean and minimal interface
- No fabricated testimonials, user numbers, or company logos

## Product Preview

The homepage includes an interactive task card where users can:

1. View today's tasks
2. Mark tasks as completed
3. See their progress percentage update
4. Add a new task

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive CSS
- GitHub Pages
